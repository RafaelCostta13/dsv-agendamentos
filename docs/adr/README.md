# Architecture Decision Records

Este diretório registra decisões arquiteturais aprovadas para o projeto DSV Doca Agenda.

Formato:

`NNNN-titulo-da-decisao.md`

Não alterar retroativamente o conteúdo de uma decisão já adotada para esconder uma mudança. Quando a arquitetura mudar, criar uma nova ADR que substitua a anterior.
