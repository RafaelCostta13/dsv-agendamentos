# Requisitos Funcionais

A nova implementação começa do zero.

Nenhum RF da tentativa anterior deve ser considerado vigente automaticamente.

Os novos requisitos serão adicionados sequencialmente neste diretório.

Padrão de trabalho:

1. criar RF;
2. implementar somente o RF atual;
3. testar;
4. homologar;
5. avançar para o próximo RF.
